# pq-briefs

Public, phone-friendly question pages ("briefs") shared with clients. Published with GitHub Pages.

- Each brief lives in its own folder with a hard-to-guess suffix; the site root lists nothing.
- Pages contain **questions only**: never client answers, names or notes (those live in the private `pq-empresa` repo).
- Pages carry `noindex, nofollow`, but anyone with the link can open them.
